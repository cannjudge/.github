# CANNJudge

Ascend C 算子竞赛的归档：题面、实现、性能记录与复盘。

维护者：[holtwood](https://github.com/holtwood)

> 本组织的仓库均为私有，仅用于个人与协作团队的赛事记录，不对外公开。

## 仓库命名

| 前缀 | 含义 |
|------|------|
| `2026-challenge-` | 主赛题 |
| `2026-ladder-` | 天梯赛题 |
| `2026-power-` | 电力专场 |
| `shared-infra` | 跨题共用的设备调度、提交校验与规范 |
| `ledger` | 台账：题目、状态、账号与成绩 |

## 每个赛题仓库包含

- 题面来源与约束
- Ascend C 实现与构建脚本
- 正确性测试与边界用例
- 性能记录（绑定具体硬件与 CANN 版本）
- 赛后复盘：哪些尝试有效、哪些无效

## 边界

性能数字只在记录的硬件（910B2）和 CANN 版本下成立，不跨平台外推。赛事期间的账号、提交记录与成绩只在 `ledger` 中维护。
